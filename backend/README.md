# Prisim RMIS – Backend

Empty for now. This is where the API for the frontend will live.

What the frontend needs from it (today it uses sample data in `frontend/src/data/mock.ts`):

- **Auth & roles** – login, users, role permission matrix
- **Branches** – central kitchen and outlets
- **Accounting** – bill upload, OCR results, verified bills (credited / other purchase expense), food costing
- **Kitchen** – indents, stock, purchase orders, vendors
- **Money** – sales, expenses, deductions rules, salary / payroll
- **Settings** – OCR on/off per branch, integrations, AI models
